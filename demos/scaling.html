Scaling laws, and compounding reliability

Chapters 9 and 11. Kaplan et al. (2020) found that test loss falls as a power law in model size: L(N) = (Nc/N)α, with α ≈ 0.076. The curve below is that formula, not measured data; the three markers show the sizes of GPT-1, 2 and 3 for reference.

Things to try

  • Switch between linear and log–log axes. On linear axes the same law looks like a cliff followed by a wall ("diminishing returns!"). On log axes it is a straight line with no sign of stopping. Both are honest pictures of the same function; much public argument about "hitting a wall" is an argument about which plot to look at.
  • Read the stat: at α = 0.076, each 10× in parameters cuts the loss by only about 16%. Progress on this curve is bought with exponentially growing compute.
  • Add an irreducible floor (the true entropy of text, which no model can beat). On log axes the line now bends. Whether and where real curves bend is the scaling debate in one picture.

Compounding reliability

Chapter 11. If an agent gets each step right with probability p, a task of n steps (with no error recovery) succeeds with probability pⁿ.

  • At 99% per step, a 100-step task succeeds about a third of the time. To make a 1,000-step task reliable you need roughly 99.99%. This is why agents arrived later than chatbots, and why a model that is only "slightly" more reliable can suddenly do much longer tasks: the idea behind METR's time-horizon measure.
