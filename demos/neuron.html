A single neuron

Chapter 1. One neuron computes w₁·x + w₂·y + b and fires if the result is positive. Geometrically it makes one straight cut through the plane. The weights set the cut's orientation; the bias slides it.

Things to try

  • With the two clusters, find weights by hand that classify every point. Notice many settings work.
  • Press Run Rosenblatt's learning rule and watch the knobs turn themselves: each mistake nudges the weights toward the misclassified point.
  • Switch to XOR. Try by hand, then run the learning rule. It never settles: no single straight cut can do it. This is the limitation Minsky and Papert made famous, and the reason networks need hidden layers. Then go to the network playground and solve it with one.
