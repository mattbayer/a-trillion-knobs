Attention, by hand

Chapters 6 and 7. One attention head, for one token. The word "it" sends out a query vector (dashed). Every other token advertises a key vector. The dot product of query and key scores the match; softmax turns scores into weights; the output is the weighted blend of the tokens' values (shown here as colours). Drag any arrowhead.

"The trophy would not fit in the suitcase because it was too big."

Things to try

  • Swing the query round to point along each key in turn. Attention goes to whichever key is best aligned: retrieval by content, not by position.
  • Point the query between "trophy" and "suitcase". The output is a blend. Attention is a soft lookup: a weighted average, which is what makes it differentiable and so trainable by backprop.
  • Turn sharpness up: the softmax approaches a hard, winner-take-all lookup. Turn it down: a uniform average of everything. A trained head sets its own sharpness through the length of its query and key vectors.
  • Drag a key to point opposite the query: that token is actively ignored. Note that nothing here depends on where a token sits in the sentence. Raw attention has no sense of order, which is why position must be added to the embeddings.
  • In a real transformer, the query, key and value are each a learned matrix times the token's current vector, in hundreds of dimensions, and there are dozens of heads per layer asking different questions at once.
